# Security policy

coolAI Gate 0.2 is experimental. No independent security audit or production
certification has been performed. The supported development line is 0.2.x.

For a security issue, use GitHub's **Report a vulnerability** facility if enabled
for this repository. If unavailable, open a minimal issue requesting a private
reporting channel without exploit details, credentials or personal data.
Do not post sensitive examples publicly.

Include the version, affected configuration, impact, and a minimal reproduction
using fictional data through the agreed private channel.

See [the security model](docs/security-model.md) for the enforcement boundary,
approval-key assumptions, deployment requirements and known limitations.
